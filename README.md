## Featured projects

### [CloudMentor AI](https://github.com/tonthatgiahuy16/CloudMentor-AI)

A locally verified end-to-end platform for document ingestion and subject-scoped RAG. It uses FastAPI, React, PostgreSQL, and Chroma to process PDFs, track document lifecycle, preserve source metadata, and return answers with document and page references.

- **Verified workflow:** create a subject, upload and index a PDF, ask a scoped question, inspect its sources, delete the document, and confirm it is removed from active retrieval.
- **Data boundary:** PostgreSQL owns document metadata and lifecycle state; Chroma stores the derived retrieval index.
- **Quality checks:** backend tests and frontend lint/build checks run in GitHub Actions.

### [Social Media Sentiment Pipeline](https://github.com/tonthatgiahuy16/social-media-sentiment-bigdata-pipeline)

A coursework batch pipeline processing approximately 1.6 million Sentiment140 records with HDFS, PySpark, partitioned Parquet, Spark ML, and FastAPI with MongoDB. The repository also contains a separate Kafka streaming demonstration with synthetic messages and an Airflow scheduling prototype.
